Premise

The spec describes structure, not semantics. The AI instance is told only how to organize its output — never why. Presentation lives in the application layer, where it belongs.

Principle
Instruct structure, not semantics. The AI emits markdown. The app decides what it looks like.
Workflow

How It Flows

One markdown document in. One HTML document out. The intermediate format stays portable, the styling stays editable.
